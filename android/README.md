# Android

Тренажёр устанавливается на Android двумя способами. Первый работает сразу,
второй нужен только для публикации в Google Play.

## 1. Установка как PWA (готово, ничего собирать не нужно)

Приложение — установимое PWA: манифест, service worker и иконки уже в `public/`.
На телефоне откройте сайт в Chrome и выберите «Установить приложение» — в меню
браузера или по кнопке внизу страницы, которую Chrome показывает, когда условия
установки выполнены.

После установки приложение:

- запускается с иконкой с рабочего стола, без адресной строки (`display: standalone`);
- переживает обрыв связи — вместо ошибки браузера показывает понятную заглушку;
- синхронизирует прогресс через аккаунт, то есть тренировка на телефоне и на
  ноутбуке продолжается с одного места.

Требования Chrome к установке: **HTTPS** (на `localhost` тоже работает),
зарегистрированный service worker и манифест с иконками 192 и 512 пикселей.
Все три пункта покрыты тестом `tests/Feature/PwaTest.php`.

## 2. Сборка APK / AAB для Google Play (Trusted Web Activity)

TWA — тонкая нативная обёртка над тем же сайтом: Play получает настоящий APK,
а код остаётся один. Нужен компьютер с доступом к `dl.google.com` (в среде, где
писался проект, он закрыт политикой сети, поэтому **этот шаг здесь не собирался
и не проверялся** — команды даны по документации Bubblewrap).

```sh
npm install -g @bubblewrap/cli
bubblewrap init --manifest https://ВАШ-ДОМЕН/manifest.webmanifest
bubblewrap build            # на выходе app-release-signed.apk и app-release-bundle.aab
```

Bubblewrap сам скачает Android SDK и JDK при первом запуске и спросит пароль
для хранилища ключей — **не теряйте его**: без того же ключа обновление
приложения в Play загрузить нельзя.

### Проверка владения доменом

Чтобы приложение открывалось без адресной строки, Android сверяет подпись APK
с файлом на сайте. Заполните `public/.well-known/assetlinks.json`:
отпечаток `SHA-256` печатает `bubblewrap fingerprint list`, а имя пакета — то,
что вы указали при `init`.

Проверить результат: `https://ВАШ-ДОМЕН/.well-known/assetlinks.json` должен
открываться публично и отдавать `application/json`.

### Что обязательно до публикации

- Домен с валидным HTTPS-сертификатом и `TRUSTED_PROXIES`, если сайт за прокси.
- `APP_DEBUG=false` — иначе ошибка покажет пользователю содержимое конфигурации.
- Политика конфиденциальности: Play требует ссылку, раз приложение собирает
  почту и пароль.
- Скриншоты и описание в Play Console.

## Нативный клиент на API

Если понадобится полноценное нативное приложение (офлайн-очередь ответов,
уведомления о повторениях, запись голоса), сервер уже готов: `routes/api.php`
отдаёт токены Sanctum и весь цикл тренировки. Описание эндпоинтов — в
`README.md`, раздел «API для мобильного клиента».
